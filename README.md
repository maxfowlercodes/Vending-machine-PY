# Vending Machine - Python

A vending machine software built by Max Fowler within python code

# General Infomation
No external imports are required for this python code - only import is **sys** and **time** which are installed in python already.
If you would like to change the items or the cost of any of the items, please do this from the **<ins>itemlist</ins>** and the **<ins>itemslistcost</ins>**.
Ensure you enter the correct ID's or you will be stuck in a loop.

Please note this machine is built to support the following coins:
£1, 50 Pence, 20 Pence, 10 Pence

If you enter anything with a .5 remainder it will not be returned due to 5P coins not being supported in our machine.

# How to run

**GH CLI** 
> gh repo clone maxfowlercodes/Vending-machine-PY


**Git installed**
 > git init - 
 > git pull https://github.com/maxfowlercodes/Vending-machine-PY.git main 


**Next Steps:**

Ensure python is installed on your device, and on your code editor.
You can do this by running python --version. If no version shows it is not properly installed on your device.


CD into the folder with the files, using **cd foldername**

> python vending-machine.py

The script will then load within your terminal and run.
